젠트리 (Zentry)

인터랙티브 웹 경험 구현

프로젝트 개요

젠트리는 수의사와 반려동물 관리를 위한 통합 플랫폼입니다. Flutter로 개발한 수의사 앱(Vet)과 React로 구축한 관리자 웹사이트로 구성되어 있으며, 최신 웹/모바일 기술을 활용하여 효율적인 동물 병원 관리 시스템을 제공합니다.

담당 역할

수의사 앱 (Flutter)

  • Flutter 기반 모바일 앱 개발
  • 수의사 진료 기록 관리 기능 구현
  • 반려동물 정보 관리 시스템
  • 크로스 플랫폼(iOS/Android) 개발

관리자 웹사이트 (React)

  • React + TypeScript 기반 관리자 페이지 개발
  • 병원 운영 관리 대시보드 구현
  • 데이터 시각화 및 통계 기능
  • 반응형 웹 디자인 적용

기술 스택

Mobile (Vet App)

Flutter, Dart, iOS/Android

Web (Admin)

React, TypeScript, JavaScript

Styling

CSS3, Responsive Design, Material Design

Tools

Git, Firebase, REST API
