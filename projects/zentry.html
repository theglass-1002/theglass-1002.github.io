젠트리 (Zentry)

인터랙티브 웹 경험 구현

프로젝트 개요

젠트리는 최신 웹 기술과 인터랙티브한 사용자 경험을 결합한 프로젝트입니다. React와 TypeScript를 활용하여 동적이고 반응형인 웹 애플리케이션을 구현했습니다.

담당 역할

프론트엔드 개발

  • React + TypeScript 기반 웹 애플리케이션 개발
  • 인터랙티브 UI/UX 구현
  • 반응형 웹 디자인 적용
  • 성능 최적화 및 사용자 경험 개선

기술 스택
