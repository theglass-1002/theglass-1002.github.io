스케치스 (Skeches)

스케치 자료를 올리고 종류별로 정리해, 자료를 보면서 스케치 능력을 향상시키는 안드로이드 앱. 2개월간 혼자 기획하고 만들었습니다.

프로젝트 개요

스케치스는 스케치 자료를 올릴 수 있으며, 자료를 종류별로 정리하고 자료를 보면서 스케치 능력을 향상시키는 안드로이드 앱입니다.

그림 연습에서 실제로 시간을 잡아먹는 건 그리는 시간이 아니라 참고할 자료를 찾는 시간이었습니다. 그래서 자료를 모으는 기능과 분류하는 기능을 같은 무게로 두고, 보면서 바로 연습할 수 있는 흐름을 만들었습니다.

담당 범위

2개월간 혼자 진행했습니다.

  • 아이디어 제공 — 기여도 100%
  • 프론트엔드 개발 — 기여도 100%

주요 기능

  • 스케치 자료 업로드 — 참고 자료를 올려 모아 둡니다.
  • 종류별 분류 — 자료를 카테고리로 정리해 필요한 것만 골라 봅니다.
  • 자료 열람 — 모아 둔 자료를 보면서 연습합니다.

외부 자료 연동에는 카카오·네이버 API를, 영상 참고 자료에는 유튜브 API를 사용했습니다.

기술 스택

  • Java (Android)
  • 카카오 API
  • 네이버 API
  • 유튜브 API
남은 자료 — 이 페이지에는 앱 시작 화면 외의 캡처가 없습니다. 자료 업로드와 분류 화면은 위 작품 영상에서 확인할 수 있습니다.
