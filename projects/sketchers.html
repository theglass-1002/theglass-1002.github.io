프로젝트 소개

그림 연습에서 시간이 가장 오래 걸리는 건 참고 자료를 찾는 일이었습니다. 그래서 자료를 모으는 기능과 분류하는 기능을 함께 만들고, 보면서 바로 연습할 수 있게 했습니다.

담당 범위

  • 아이디어 제공 — 기여도 100%
  • 프론트엔드 개발 — 기여도 100%

주요 기능

  • 업로드 — 참고 자료를 올려 모아 둡니다.
  • 분류 — 카테고리별로 정리해 필요한 것만 봅니다.
  • 열람 — 모아 둔 자료를 보며 연습합니다.

외부 자료는 카카오·네이버 API, 영상 자료는 유튜브 API를 썼습니다.

사용 기술

  • Java (Android)
  • 카카오 API
  • 네이버 API
  • 유튜브 API
참고 — 시작 화면 외의 캡처가 없어, 나머지 화면은 위 작품 영상으로 대신합니다.
