초등학생의 문해력 향상을 위한 교육용 윈도우 프로그램. 게임 형식의 학습 흐름과 아동 친화적 인터페이스를 담당했습니다.

프로젝트 개요

초등학생의 문해력 향상을 위한 교육용 윈도우 프로그램입니다. 게임 형식의 인터랙티브한 학습 경험을 통해 문해력을 효과적으로 향상시키는 것을 목표로 했습니다.

웹 서비스가 아니라 교실 PC에 설치해 쓰는 윈도우 프로그램이라는 조건이 화면 설계에 그대로 반영됐습니다. 브라우저 주소창도, 뒤로 가기도 없기 때문에 프로그램 안에서 지금 어디에 있고 어떻게 돌아가는지를 화면이 직접 알려줘야 했습니다.

담당 범위

  • 윈도우 프로그램 UI/UX 개발 설치형 프로그램 환경에 맞춘 화면 구성을 담당했습니다.
  • 인터랙티브 학습 콘텐츠 구현 학습 단계와 반응을 화면으로 구현했습니다.
  • 게임형 학습 시스템 개발 학습 진행을 게임 흐름으로 바꾼 화면을 만들었습니다.
  • 아동 친화적 인터페이스 설계 글을 배우는 단계의 사용자를 대상으로 글자 크기와 버튼 크기, 안내 문장을 조정했습니다.

대상이 초등학생이라 읽어야 알 수 있는 안내를 최소화하는 것이 중요했습니다. 문해력을 기르는 프로그램에서 사용법 설명이 어려우면 그 자체로 장벽이 되기 때문에, 글보다 형태와 위치로 다음 행동을 알리는 방향으로 잡았습니다.

기술 스택

  • Windows 데스크톱
  • HTML5 · CSS3 · JavaScript
  • 인터랙티브 학습 모듈
