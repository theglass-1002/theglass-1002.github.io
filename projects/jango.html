장고 (Jango)

장애인 구직자, 기업, 복지사를 연결하는 통합 고용 플랫폼

프로젝트 개요

장고는 장애인 구직자, 기업, 복지사를 연결하는 통합 고용 플랫폼입니다. AI 모의면접 기능을 탑재하고 WCAG 2.1 AA 수준의 웹 접근성을 준수하여, 장애인 고용의 장벽을 낮추고 더 나은 취업 기회를 제공합니다.

구직자, 기업, 복지관 3개의 독립적인 웹사이트로 구성되어 있으며, 각 사용자 그룹의 니즈에 맞춘 최적화된 경험을 제공합니다.

담당 역할

3개 버전 풀스택 개발 (프론트엔드 중심)

  • React 19 + TypeScript 기반 프론트엔드 아키텍처 설계
  • 구직자/기업/복지관 3개 독립 웹사이트 개발
  • WCAG 2.1 AA 수준 웹 접근성 구현
  • AI 모의면접 UI/UX 설계 및 구현
  • Firebase 실시간 알림 시스템 연동

주요 기능

  • AI 모의면접: 이력서 기반 맞춤형 질문 생성 및 실시간 피드백
  • 3개 독립 웹사이트: 구직자/기업/복지사 각각의 맞춤형 인터페이스
  • 웹 접근성: WCAG 2.1 AA 준수로 모든 사용자가 쉽게 이용 가능
  • 통합 관리 시스템: 채용 공고 및 이력서 통합 관리
  • 실시간 알림: Firebase를 통한 실시간 알림 및 인증
  • 모의면접 대시보드: 진행 현황 및 결과 시각화

기술 스택

Frontend

React 19, TypeScript, Vite, React Router

Backend & Database

Firebase (Authentication, Firestore, Cloud Functions)

AI Integration

AI 모의면접 API 연동

Accessibility

WCAG 2.1 AA, Screen Reader Support
