프로젝트 개요

케어팜은 간병인이 필요한 사용자와 간병인을 하고 싶은 사용자를 매칭시켜 주며, 주변 요양 시설을 찾을 수 있는 안드로이드 앱입니다.

간병은 급하게 필요해지는 경우가 많고, 그때 정보를 찾을 여유가 없습니다. 그래서 구인·구직 게시판 형태가 아니라 양쪽 조건을 등록해 두고 매칭되는 구조로 잡았습니다. 동시에 시설을 직접 찾는 경로도 필요하다고 봐서, 지도 기반 요양 시설 검색을 함께 넣었습니다.

담당 범위

3개월간 혼자 진행한 프로젝트로, 아이디어부터 배포까지 전 과정을 담당했습니다.

  • 아이디어 제공 — 기여도 100%
  • 프론트엔드 개발 — 기여도 100%
  • 백엔드 개발 — 기여도 100%

혼자 하는 프로젝트라 화면과 서버 사이에서 타협할 상대가 없었습니다. 대신 기능을 하나씩 끝까지 붙여 동작하는 상태를 유지하면서 늘리는 방식으로 진행했습니다.

주요 기능

  • 간병인 매칭 — 간병이 필요한 사용자와 간병인 희망자를 연결합니다.
  • 주변 요양 시설 검색 — 위치를 기준으로 인근 요양 시설을 찾습니다.
  • 회원가입 및 프로필 관리 — 양쪽 사용자의 조건을 등록·수정합니다.

지도와 장소 검색은 카카오·네이버 API로 붙였고, 서버 통신은 Volley 라이브러리로 처리했습니다.

기술 스택

  • Java (Android)
  • PHP
  • MySQL
  • Apache
  • 카카오 API
  • 네이버 API
  • Volley
남은 자료 — 이 페이지에는 앱 시작 화면 외의 캡처가 없습니다. 매칭 흐름과 요양 시설 검색 화면은 위 작품 영상에서 확인할 수 있고, 정지 화면 캡처를 확보하면 이 페이지에 추가할 예정입니다.
