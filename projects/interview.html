프로젝트 개요

면접왕은 면접 준비생을 위한 맞춤형 AI 모의면접 서비스입니다. 사용자는 대입 준비와 취업 준비 중 필요한 쪽을 골라 연습하고, AI 분석을 거친 결과 리포트로 개인별 피드백을 받습니다.

생활기록부 기반 질문 생성 — 생활기록부를 등록하면 AI가 내용을 분석해 맞춤형 면접 질문을 만듭니다. 등록 과정에는 필수 약관 확인과 동의 절차가 들어갑니다.

학과별 예상 질문 — 계열과 학과를 입력하면 해당 학과의 예상 질문을 확인할 수 있습니다. 경영학, 법학, 의학 등 학과별로 질문이 나뉩니다.

승무원 특화 버전은 대한항공, 아시아나항공 등 항공사 승무원 면접을 준비하는 지원자를 위한 흐름으로, CROVAI 가이드와 면접 중 분석(외모·화면·얼굴·목소리)을 함께 제공합니다.

담당 역할

프론트엔드 개발을 맡아 다음 범위를 담당했습니다.

  • SPA 아키텍처 설계 React 19 + TypeScript + Vite 기반으로 화면 단위를 나누고 라우팅 구조를 잡았습니다.
  • 모의면접 화상 인터페이스 구현 면접 응시 화면과 진행 상태 표시를 구현했습니다.
  • 카메라·마이크 미디어 스트림 처리 응시 전 권한 요청과 장치 상태 확인 흐름을 붙였습니다.
  • 분석 결과 시각화와 리포트 화면 면접이 끝난 뒤 받는 결과 리포트 화면을 만들었습니다.
  • 대입 / 취업 듀얼 모드 UI 설계 같은 응시 엔진을 두 갈래 사용자에게 다른 안내와 입력 항목으로 보여주도록 화면을 나눴습니다.

응시 전 준비 흐름

AI가 얼굴과 목소리를 분석하는 서비스라, 응시 환경이 어긋나면 결과 자체가 의미를 잃습니다. 그래서 바로 면접을 시작하지 않고 안내 → 주의사항 확인 → 정보 입력의 단계를 앞에 뒀습니다. 화면 상단에는 지금 어느 단계인지 보여주는 진행 표시가 계속 남아 있습니다.

주의사항은 글로만 적지 않고 지켜야 할 모습과 안 되는 모습을 그림으로 나란히 뒀습니다. 마스크를 쓴 예시에 빨간 X를 겹쳐 놓은 것처럼, 읽지 않고 넘기는 사용자도 형태만으로 구분할 수 있게 했습니다.

핵심 기능

1. 맞춤 질문 생성

  • 생활기록부 등록 — PDF로 생활기록부를 올리면 AI가 내용을 분석해 예상 질문을 만듭니다.
  • 동의 절차 — 등록 전 필수 약관 확인과 동의를 거칩니다.
  • 학과별 질문 — 계열과 학과를 고르면 그 학과에 맞춘 예상 질문을 볼 수 있습니다.

2. 실시간 AI 면접

  • 면접 중 분석 — 외모·화면·얼굴·목소리 네 가지 요소를 기준으로 분석합니다.
  • 면접 영상 녹화 — 응시 과정을 녹화해 다시 볼 수 있습니다.
  • MY AI 모의면접 — 사용자 맞춤 질문으로 진행하는 개인 모의면접입니다.

3. 분석 · 리포트

  • 심층 분석 리포트 — 응시 후 상세 피드백과 개선점을 제공합니다.
  • PDF 다운로드 — 모바일에서 결과 리포트를 PDF로 내려받을 수 있습니다.

4. 승무원 특화 흐름

  • 대입 / 취업 듀얼 모드 — 진입 시점에 목표를 선택해 이후 흐름을 나눕니다.
  • CROVAI 가이드 — 승무원 면접에 맞춘 준비 가이드를 응시 전에 제공합니다.
  • 지원 항공사 정보 입력 — 항공사 구분과 지원 항공사를 받아 질문에 반영합니다.
  • 로그인 · 회원가입 — 이메일 또는 네이버·카카오 계정으로 가입할 수 있습니다.

기술 스택

화면 단위를 잘게 나누고 상태를 타입으로 고정하는 편이 두 갈래 모드를 유지하기에 유리해 React + TypeScript 구성을 사용했습니다. 인증과 저장소는 Firebase에 맡겨 프론트엔드 쪽 작업량을 화면 흐름에 집중시켰습니다.

  • React 19
  • TypeScript
  • Vite
  • React Router
  • WebRTC · MediaStream
  • Firebase Auth · Firestore · Storage
  • AI 음성/영상/표정 분석 API

정리

면접왕에서 가장 많이 고민한 지점은 기능의 개수가 아니라 순서였습니다. AI 분석의 정확도는 사용자가 응시 환경을 제대로 갖췄는지에 크게 좌우되는데, 그 조건은 면접이 시작된 뒤에는 되돌릴 수 없습니다. 그래서 안내와 주의사항을 응시 앞단에 배치하고, 각 단계에서 빠져나갈 길과 진행 상황을 함께 보여주는 쪽을 택했습니다.

이 페이지의 화면 자료는 대입·승무원 공통 준비 흐름 구간입니다. 응시 중 화면과 결과 리포트 화면은 공개 가능한 자료를 확보하는 대로 추가할 예정입니다.
