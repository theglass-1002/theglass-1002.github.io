홀로그램 AI 키오스크

Gemini API 연동 음성 주문 카페 키오스크

프로젝트 개요

Gemini API를 연동한 음성 주문 카페 키오스크 시스템입니다. 자연어 대화로 메뉴 주문부터 결제까지 완성하는 미래형 무인 주문 시스템으로, 부산 가상융합 실증사업의 일환으로 개발되었습니다.

사용자는 홀로그램 인터페이스를 통해 AI와 대화하며 주문할 수 있으며, 직관적인 음성 인식과 시각적 피드백으로 누구나 쉽게 사용할 수 있는 접근성 높은 키오스크 경험을 제공합니다.

담당 역할

전체 프론트엔드 개발 및 AI 연동

  • 음성 인식 기반 UI/UX 설계 및 구현
  • Gemini API 연동 및 자연어 처리 로직 개발
  • 홀로그램 디스플레이 최적화 인터페이스 구현
  • 주문 플로우 및 결제 시스템 프론트엔드 개발
  • 키오스크 관리자 모드 개발

주요 기능

1. 기기 및 운영자 접근

  • 최초 로그인: 기기 초기 설정 및 인증
  • PIN 입력: 운영자 보안 인증
  • 히든 진입: 관리자 모드 접근
  • 로컬 관리 메뉴: 결제·품절·주문 일시중지 관리

2. 고객 주문 플로우

  • 시작화면: AI 홀로그램 캐릭터 환영 화면
  • 메뉴 선택: 음성 또는 터치로 메뉴 주문
  • 옵션 선택: 사이즈, 온도, 토핑 등 음성 명령으로 커스터마이징
  • 주문 확인: AI가 주문 내역 확인 및 수정 가능

3. AI 음성 인터랙션

  • 자연어 처리: "아이스 아메리카노 두 잔 주세요" 같은 자연스러운 주문
  • 실시간 피드백: 음성 인식 상태 시각적 표시
  • AI 정책: 사용자 음성 데이터 처리 정책 안내

4. 공통 요소

  • 팝업/모달: 주문 오류 및 안내 메시지
  • 매장 FAQ: 자주 묻는 질문 및 정책 문서
  • 플로우맵: 전체 주문 프로세스 플로우차트 및 시나리오 설계
