프로젝트 소개

Gemini API를 연동해 자연어 대화로 메뉴 주문부터 결제까지 끝내는 무인 주문 키오스크입니다. 부산 실증 사업으로 개발했습니다.

키오스크는 처음 쓰는 사람이 도움 없이 끝까지 가야 하는 화면입니다. 설명서를 읽지 않고, 뒤에 줄이 서 있고, 잘못 눌러도 되돌릴 수 있어야 합니다. 그래서 화면 목록보다 전체 주문 흐름과 시나리오를 먼저 정리했습니다.

제가 맡은 일

  • 음성·터치 병행 주문 화면 듣고 있는 상태를 화면에 계속 띄우고, 음성이 안 되면 같은 화면에서 손으로 이어갑니다. 인식이 세 번 연속 실패하면 화면에서 고르도록 안내합니다.
  • Gemini API 주문 해석 “아이스 아메리카노 라지 결제할게요” 한 문장에서 메뉴·수량·옵션을 뽑습니다. 이름이 여러 메뉴에 걸리면 한 번만 되묻고, 없는 메뉴와 품절 메뉴는 담기지 않게 막았습니다.
  • 주문·결제 플로우 장바구니, 주문 확인, 매장·포장 선택, 결제 실패 복구, 완료 화면까지 구현했습니다. 결제 중에는 마이크와 이동 버튼을 잠가 중복 승인을 막았습니다.
  • 매장 운영자용 관리자 모드 손님에게 보이지 않는 진입과 PIN 인증을 거쳐 결제 취소·품절·주문 접수 중단을 처리합니다.

고객 주문 흐름

  • 대기 · 시작 — 화면을 2초 정면으로 바라보거나 [주문 시작하기]를 누르면 AI가 인사하고 마이크가 켜집니다. 언어는 이 화면에서만 고를 수 있습니다.
  • 옵션 선택 — 온도·사이즈는 하나만, 토핑은 여러 개, 샷은 수량으로 고릅니다. 필수 옵션이 남아 있으면 [담기]가 눌리지 않습니다.
  • 주문 확인 — AI가 담긴 메뉴를 읽어 주고 총 금액을 말합니다. 수량과 삭제는 여기서 되고, 옵션은 지우고 다시 담아야 합니다.
  • 매장·포장 → 결제 → 완료 — 매장·포장을 고르지 않으면 결제로 넘어가지 않습니다. 결제가 끝나면 주문번호를 띄우고 15초 뒤 대기화면으로 돌아갑니다.

AI 음성 주문

  • 한 문장 처리 — “아이스 아메리카노 라지 결제할게요”처럼 메뉴·옵션·결제 의사가 한 번에 들어오면 바로 주문 확인까지 갑니다.
  • 되묻기는 한 번만 — “라떼”처럼 여러 메뉴에 걸리면 후보만 남기고 한 번 묻고, 하나만 걸리면 “딸기라떼 맞으시죠?”로 확인만 합니다.
  • 인식 상태 표시 — 듣는 중인지 처리 중인지를 화면 맨 위에 계속 띄웁니다.
  • 말 끊기 · 되돌리기 — AI가 말하는 중에 손님이 말하면 바로 멈춥니다. “그만”, “다 취소해줘”는 팝업으로 한 번 확인한 뒤 되돌립니다.

음성 입력의 가장 큰 문제는 기기가 지금 듣고 있는지 알 수 없다는 점입니다. 반응이 없으면 손님이 같은 말을 반복해 인식이 더 어긋납니다. 그래서 인식 상태를 항상 화면에 표시하고, 음성이 실패하면 같은 화면에서 터치로 넘어갈 수 있게 했습니다.

공통 요소

  • 팝업 / 모달 — 취소처럼 되돌릴 수 없는 동작은 한 번 확인합니다. 바깥을 눌러도 닫히지 않고, 버튼 대신 “네”·“아니요”라고 말해도 됩니다.
  • 무동작 타임아웃 — 주문 중 30초 동안 아무 일도 없으면 계속할지 묻고, 10초 뒤 대기화면으로 돌아가며 장바구니·언어·마이크를 초기화합니다. 결제 처리 중에는 뜨지 않습니다.

기기 · 운영자 흐름

손님 화면과 완전히 분리된 영역입니다. 영업 중에 품절 처리나 주문 중단을 해야 하는데 입구가 손님에게 보이면 안 돼서 진입 경로 자체를 숨겼습니다.

  • 히든 진입 — 좌측 상단 모서리 빈 곳을 3초간 누르면 PIN 창이 뜹니다. 대기화면과 메뉴 화면에서만 열리고, 주문·결제 중에는 반응하지 않습니다. 열 번 틀리면 1분간 잠깁니다.
  • 결제 관리 — 당일 주문만 주문번호로 찾아 전체 취소합니다. 되돌릴 수 없어서 금액을 보여 주는 확인 창을 한 번 거칩니다.
  • 품절 관리 — 토글을 누르면 저장 버튼 없이 바로 반영됩니다. 진행 중인 주문은 그대로 두고 다음 주문부터 적용되며, 같은 매장의 다른 기기와 관리자 페이지에도 반영됩니다.
  • 주문 접수 일시중지 — 화면은 켜 둔 채 새 주문만 막습니다. 진행 중이던 주문과 결제는 끝까지 처리되고, 재개하려면 PIN을 다시 입력해야 합니다.

관리 기능에는 매장에서 바로 처리해야 하는 것들만 뒀습니다. 품절과 주문 중단은 지금 눌러야 하는 일이고, 통계처럼 나중에 봐도 되는 건 넣지 않았습니다. 관리 화면을 60초 동안 두면 손님 화면으로 돌아갑니다.

사용 기술

자연어 주문 해석은 직접 규칙을 짜지 않고 Gemini API에 맡겼고, 프론트엔드는 인식 상태 표시와 주문 상태 관리에 집중했습니다.
